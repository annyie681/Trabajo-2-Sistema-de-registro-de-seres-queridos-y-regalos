# Trabajo-2-Sistema-de-registro-de-seres-queridos-y-regalos
Trabajo 2 para CV - Sistema de registro de seres queridos y regalos

Creadores: 
Hernández Morales Anahí 
López Corella David Antonio 
Sandoval López Daniela

Descripción: Es un sistema de gestión que permite registrar, buscar, editar y eliminar información detallada de personas fallecidas, incluyendo datos como fecha y causa de fallecimiento, ubicación en el panteón y la opción de adjuntar actas de defunción. Además, cuenta con un módulo de inventario para administrar regalos o arreglos, donde se puede controlar el tipo de arreglo, tamaño, precio, stock disponible y datos del proveedor. También incluye una vista de mapa para ubicación. 

Información Adicional: Creado por medio de Canva, utilizando sus herramientas para agregar, botones, animaciones e interactividad entre los distintos escenarios del sistema. En esta versión se está accediendo como administrador del programa, por lo que es posible editar los datos.
